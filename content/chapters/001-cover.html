What this book is

This is a book for people who want to actually learn Zig — not just skim its syntax. It covers the language as it stands at version 0.16.0, the latest tagged release as of May 2026. That release introduced I/O as an interface, moved much of the operating-system surface under std.Io, and brought the language meaningfully closer to its 1.0 milestone.

The book is opinionated about two things. First, that Zig rewards careful reading — every keyword does specific work, and the language has remarkably few hidden behaviors, so naming things accurately matters. Second, that you learn a systems language by writing code that touches memory, calls the operating system, and links against C — not by writing toy programs forever. So we get to the metal quickly.

Who it's for

You should be comfortable with at least one programming language. If you've written C or C++, much of Zig will feel familiar but cleaner. If you're coming from Rust, you'll find Zig less ceremonious but more responsible for your own memory. If you're coming from Go, Python, or JavaScript, you'll be doing more bookkeeping but you'll understand exactly what your program is doing — sometimes for the first time.

How to read it

The chapters are ordered so each one only depends on what came before. You can read it cover-to-cover, or jump in at the part that interests you. The right-hand panel shows the in-page table of contents; the left sidebar shows the whole book.

Use the search box at the top (or press Ctrl-K / ⌘-K) to find anything. Click the moon/sun icon for a light theme if you're reading in daylight.
