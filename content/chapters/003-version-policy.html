Zig is pre-1.0, so the compiler and standard library change between releases. A book should teach one installable compiler clearly. This book targets Zig 0.16.0.

The target for this book

Install Zig 0.16.0 when following the examples. That keeps the language rules, standard library APIs, build-system behavior, and generated docs aligned with the prose.

${note("One version while learning", `

Do not mix examples across Zig releases while you are learning the language. First get comfortable with one stable version; then release notes become useful instead of distracting.

`)}

How to check your compiler

${sh(`$ zig version 0.16.0 $ zig env`)}

zig env shows the compiler path, standard-library path, cache paths, and host target. The std_dir value is especially useful because it points to the exact standard library source your compiler uses.

Version rule for readers

  • Use 0.16.0 for every command in this book.
  • When you start a project, put .minimum_zig_version = "0.16.0" in build.zig.zon.
  • When a future stable Zig release appears, update deliberately: install the compiler, read the release notes, then update examples and dependencies together.

Practical takeaway: pin the compiler version for learning and for projects. Zig gives you enough control that version drift should be an explicit decision, not an accident.
